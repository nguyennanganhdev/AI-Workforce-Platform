ID dùng cho các bước tiếp theo
Chọn “Dùng giá trị” ở phản hồi để điền ID vào trường tương ứng. Chỉ lưu trong bộ nhớ của trang, tải lại sẽ mất.

  
Lịch sử trong phiên
Chọn một dòng để xem lại phản hồi. Khi gặp 409, đọc lại chi tiết tài nguyên để lấy version mới; không tự gửi lại thao tác ghi.
