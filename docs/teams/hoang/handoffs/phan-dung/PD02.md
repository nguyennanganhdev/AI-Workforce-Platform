## API và hành vi

```python
class IntakePort(Protocol):
    async def evaluate_policy(self, request: dict) -> dict: ...
    async def search_knowledge(self, request: dict) -> dict: ...
```

Đây là protocol nội bộ đề xuất, không API backend đã freeze. Request giữ JSON
message/context PH01; `signal` là CancellationToken local Python. Identity/ACL/file
references do backend xác minh. Model/browser không tự chọn tenant hoặc scope.

Policy versioned emergency/needs_staff được ưu tiên trước retrieval. Knowledge
sufficient bắt buộc answer/retrievalRunId/citations có ID/version/chunk, trả lời ngay
không tạo ticket. Insufficient hỏi theo policy, không tự suy ra cần nhân viên.
Policy/knowledge sai hoặc port lỗi chuyển review với exception đã lọc;
CancellationToken không bị nuốt thành review. Graph wrappers áp dụng async budget;
backend adapter vẫn phải xử lý I/O cancellation và HTTP errors thật.

Generic PD01 optional intake giữ harness; production PD02 phải inject port thật.
Business WorkflowOptions cần intake, resolve_session và request_policy khi chạy;
policy staff_required xác nhận mới đi vào draft
PD03, rồi assessment/route/ACK/wait PD04–PD05. Generic handoff chỉ human review.
Active ticket bypass intake; không tạo draft mới từ follow-up. Policy intake không
thay official triage/priority/severity/SLA hoặc tự publish emergency notification.
