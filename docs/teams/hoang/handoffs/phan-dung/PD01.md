## API và hành vi

```python
from src.graph import GraphDependencies, ReceptionFactoryOptions, create_reception_graph_factory

factory = create_reception_graph_factory(ReceptionFactoryOptions(bindings=bindings))
graph = factory.create(GraphDependencies(model=model, tools=tools, checkpointer=checkpointer))
result = await graph.run(request)
```

Ví dụ composition dùng các dependency thật do owner inject; không có default model,
tool hoặc RAM saver production. Model cung cấp `ainvoke(messages)`, tool cung cấp
`async invoke(request)`. Các method graph `run`, `resume`, `read` là async;
`stream` là async iterator. Wire JSON giữ shape PH01, Python consumer version riêng
`0.1.0-python.draft.1`; không conform trực tiếp TypeScript interface qua import.

State tách reported/confirmed/inferences. Model chỉ chọn operation allowlist;
confirmed được project từ backend success qua binding validator cùng provenance.
Plan/input/key được checkpoint trước side effect với `durability="sync"`.
Accepted/lost response/sai schema giữ pending; reconcile cùng key/input, không retry
mutation chưa rõ kết quả. Not_applied chuyển human review, không tự dispatch/đóng ticket.

Mặc định 8 quyết định, 3 lần hỏi mỗi session, budget 10.000 ms cho async model/port.
Read/run/resume kiểm tra owner/version; resume kiểm tra interrupt/source và event
binding/ticket/generation/version. Stream phát reply sau graph và một terminal result.
Completion chỉ kết thúc lượt hội thoại. Generic PD01 không có recovery method;
PH03 cần giải quyết pending node sau abort/crash; business workflow có `recover` riêng.

## Dependency và giới hạn

PH/DD cần freeze Python bindings, package namespace/dependency pins/bridge runtime,
auth/binding, persistent saver, lease/fencing, idempotency, event ingress/reconcile.
Thread codec là compact JSON tuple `[namespace, threadId]`, root checkpoint_ns rỗng;
PH03 chốt namespace mới/migration/retention trước production. Python từ chối marker
TypeScript cũ, không reset hoặc migrate âm thầm. Generic start operation chưa có dedup
để caller replay tùy ý; owner phải authorize và chống replay trước entrypoint.

Không sửa shared contracts/entrypoint/package/lockfile, HTTP client/DB/UI/Supervisor
hoặc worker. Chưa LLM/backend/ACL/storage/restart/multi-replica/E2E thật.
