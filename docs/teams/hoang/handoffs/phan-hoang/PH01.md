## Hiện trạng sau khi PD chuyển Python

Cập nhật theo yêu cầu người dùng ngày 30/09/2026: code graph/prompt/tests Reception
và schema/narrative/layout/tests Report do Phan Dũng viết hiện dùng Python. Runtime,
entrypoint, model adapter, health transport và contracts PH01 vẫn TypeScript/Bun;
không được chuyển ngôn ngữ hoặc sửa code trong lần cập nhật tài liệu này.

- Generic graph: [factory.py](../../../../../agent-reception/src/graph/factory.py),
  factory `create_reception_graph_factory(ReceptionFactoryOptions(...))`.
- Business graph: [workflow.py](../../../../../agent-reception/src/graph/workflow.py),
  factory `create_reception_workflow_factory(WorkflowOptions(...))`.
- Python consumer interfaces: [workflow_contracts.py](../../../../../agent-reception/src/graph/workflow_contracts.py).
  Composer inject `GraphDependencies(model, tools, checkpointer)`; model có
  `ainvoke(messages)`, tools có `async invoke(request)`, saver là LangGraph Python
  async-compatible. Không inject trực tiếp model/checkpointer TypeScript vào Python.
- `run`, `resume`, `read` là async; `stream` là async iterator. Business graph thêm
  `recover` để reconcile pending plan sau fenced recovery claim; generic graph chưa có
  recovery method. Wire JSON giữ shape context/message/event PH01 và schema Supervisor v1.
- Python consumer contract `0.1.0-python.draft.1`, generic marker `pd01-python-1`,
  business marker `pd-workflow-python-2`. PH01 TS contract vẫn `0.1.0-draft.1`;
  schema envelope cùng số 1 không chứng minh checkpoint tương thích giữa hai runtime.
  PH03 phải chốt namespace mới hoặc migration rõ ràng, không tự reset session.
- TypeScript không import/chạy trực tiếp `.py`. PH/Team 5 cần chốt Python composition
  hoặc cầu nối process/service, package namespace, dependency pins và deployment.
  Chưa có cầu nối production, backend tools/persistence/event registry hoặc DOCX export thật.

Kết quả đã chạy ở lượt chuyển Python: **137 Python consumer tests pass**;

## Kiểm chứng nền tảng PH01 TypeScript

Môi trường: Windows, Bun 1.3.14. Máy chưa có Bun trong PATH ban đầu; phiên làm việc
dùng binary gói `@oven/bun-windows-x64@1.3.14` chính thức tải vào thư mục local
`.codex-artifacts/ph01/tooling/` (gitignored), không cài global hoặc đổi PATH hệ thống.
Chạy các lệnh trong `agent-reception/`, thêm thư mục binary vào PATH của process:

| Kiểm tra | Kết quả |
|---|---|
| `bun install --ignore-scripts` | Tạo lockfile Reception và cài dependency thành công. Cache local nằm trong `.codex-artifacts/ph01/cache`. |
| `bun install --frozen-lockfile --ignore-scripts` | Thành công, lockfile không cần cập nhật. |
| Fresh install trong thư mục trống | Copy manifest/lock vào `.codex-artifacts/ph01/frozen-install-check`; frozen install thành công 39 packages, không dựa vào `node_modules` có sẵn. |
| `bun run test` | 25 pass, 0 fail; 5 file test. |
| `bun run typecheck` | Thành công, gồm cả negative compile-time consumer checks. |
| Biome 2.5.10 lint/format | Lint `src/` và `tests/` không warning; format check 15 file TS/JSON đạt. Chạy giới hạn Reception, không format toàn repo. |
| HTTP bootstrap | Test mở listener loopback/cổng tạm, GET health 200 đúng body, POST run 404, đóng server trong finally. |
| Import / CLI lỗi | Child process không có provider credentials; import không đọc config/mở server; chạy CLI với config sai exit 1, không in giá trị đầu vào. |
| Capability LangGraph | Framework thật, model/tool giả, MemorySaver: interrupt trước tool, stream resume, checkpoint hoàn thành, hai thread trong RAM tách dữ liệu. |

Không gọi model/backend thật hoặc database. Test framework không đại diện cho
durability, lease/fencing, auth tenant hoặc business intake. Không chạy migration.
`git diff --check` đạt; root manifests/lockfile, `tsconfig.base.json` và sample
`agent-langgraph/` không thay đổi. Các file vẫn ở working tree, chưa commit.
