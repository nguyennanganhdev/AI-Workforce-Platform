  timeout/cancel/idempotency và phân biệt accepted/success/unknown outcome;

  fixture dùng chung tại `tests/support`; preload tắt remote tracing trong test.
  Không sửa graph/tools của thành viên khác.

## Kiểm chứng

Môi trường: Windows, Bun 1.3.14. Máy chưa có Bun trong PATH ban đầu; phiên làm việc
dùng binary gói `@oven/bun-windows-x64@1.3.14` chính thức tải vào thư mục local
`.codex-artifacts/ph01/tooling/` (gitignored), không cài global hoặc đổi PATH hệ thống.
Chạy các lệnh trong `agent-reception/`, thêm thư mục binary vào PATH của process:

| Kiểm tra | Kết quả |
|---|---|
| `bun install --ignore-scripts` | Tạo lockfile Reception và cài dependency thành công. Cache local nằm trong `.codex-artifacts/ph01/cache`. |
| `bun install --frozen-lockfile --ignore-scripts` | Thành công, lockfile không cần cập nhật. |
| Fresh install trong thư mục trống | Copy manifest/lock vào `.codex-artifacts/ph01/frozen-install-check`; frozen install thành công 39 packages, không dựa vào `node_modules` có sẵn. |
| `bun run test` | 25 pass, 0 fail; 5 file test. |
| `bun run typecheck` | Thành công, gồm cả negative compile-time consumer checks. |
| Biome 2.5.10 lint/format | Lint `src/` và `tests/` không warning; format check 15 file TS/JSON đạt. Chạy giới hạn Reception, không format toàn repo. |
| HTTP bootstrap | Test mở listener loopback/cổng tạm, GET health 200 đúng body, POST run 404, đóng server trong finally. |
| Import / CLI lỗi | Child process không có provider credentials; import không đọc config/mở server; chạy CLI với config sai exit 1, không in giá trị đầu vào. |
| Capability LangGraph | Framework thật, model/tool giả, MemorySaver: interrupt trước tool, stream resume, checkpoint hoàn thành, hai thread trong RAM tách dữ liệu. |

Không gọi model/backend thật hoặc database. Test framework không đại diện cho
durability, lease/fencing, auth tenant hoặc business intake. Không chạy migration.
`git diff --check` đạt; root manifests/lockfile, `tsconfig.base.json` và sample
`agent-langgraph/` không thay đổi. Các file vẫn ở working tree, chưa commit.
