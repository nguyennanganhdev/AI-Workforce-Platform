## Thay đổi

- `agent-reception/src/tools/contracts.py`: input/output model strict cho đủ 14
  operation, result union success/accepted/failure, kiểu message Supervisor V2.
  Pydantic từ chối field thừa, enum sai, coercion, version sai kiểu, timestamp thiếu
  timezone và boolean giả. Fact có giá trị `null` được giữ nguyên khi qua HTTP.
- `agent-reception/src/tools/validation.py`: catalog `ph16.draft.1`, metadata
  `system/internal`, phân loại read/mutation, không expose tool cho LLM. Validation
  độc lập HTTP; check ticket/generation, correlation, event tenant/binding/version,
  receipt handoff và wait, xác nhận file, procedure/consent/version/expiry.
- `agent-reception/src/tools/facade.py`: 14 method có kiểu input và
  `Success[Output] | Accepted | Failure`; context/key là keyword-only. Consumer gọi
  method cố định, không tự tạo operation tùy ý. Injected port cũng bị validate.
- `agent-reception/src/tools/backend.py`: giữ HTTP baseline và endpoint cấu hình,
  tách validator ra module riêng; execute/reconcile dùng cùng canonical request và
  result validation. Service token không xuất hiện trong repr của config.
- `agent-reception/src/tools/__init__.py`: export facade/catalog/error công khai
  cho internal runtime; không đăng ký vào model hoặc backend registry.
- `agent-reception/tests/tools/test_backend.py`: giữ ba regression baseline,
  thay fixture tối thiểu không hợp lệ bằng request/result đầy đủ theo contract.
- `agent-reception/tests/tools/tool_fixtures.py`, `test_contracts.py`,
  `test_flow_contract.py`: fixture tổng hợp, HTTP mock và test ràng buộc mới.
- `agent-reception/requirements.txt`: thêm dependency trực tiếp
  `pydantic==2.13.5`; `requirements-test.txt` pin `pytest==9.1.1`, `ruff==0.16.9`.
- `agent-reception/README.md`: cách cài/test và sử dụng facade, giới hạn consumer.

Không sửa graph/prompt, backend API, SQL/migration, shared schema, UI, runtime của
Đông hoặc file thuộc Dương Dũng. Không tạo fake backend/model trong production.

Context model chỉ kiểm shape, không chứng minh quyền. Backend phải xác thực token,
binding/principal và kiểm quyền file, trạng thái chờ và expected version. Ticket
version là opaque string: tool không tự sắp thứ tự version sau mutation/status.
Event buffered mới hơn có thể đến sau wait nhưng vẫn phải cùng correlation/scope.
